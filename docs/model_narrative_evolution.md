## v1.0 — 基础模型（当前）

### 日期
2025-05-17

### 模型结构

**名称**：OPFA-QKAN-Mamba

**架构公式**：
```
y = x + sigmoid(OPFA_QKAN(down(x), c)) × Mixer(x)
```

**组件**：

| 组件 | 实现 | 参数量 |
|------|------|--------|
| 输入投影 | Linear(d_input → latent_dim) | d_input × latent_dim |
| 门控 | OPFA-DARUAN (6 reps, 3 bands) | ~200 |
| 输出投影 | Linear(latent_dim → d_input) | latent_dim × d_input |
| 混合器 | Mamba SSM / CausalConv1d (fallback) | ~d_input² |
| 分类头 | Linear(d_input → 1) | d_input |
| 概念投影 | Linear(d_input → d_ontology) | d_input × d_ontology |

**OPFA-DARUAN 三个 QML 修改**：

1. **多轴编码**：感染(σ_z) / 循环(σ_x) / 器官(σ_y)
2. **本体分区频率**：3 频段各 2 层，频段边界固定，段内权重可学习
3. **自适应测量**：α·σ_x + β·σ_y + γ·σ_z，权重由上下文决定

**超参数**：
```
latent_dim = 16
d_ontology = 16
reps = 6 (每频段 2 层)
bands = 3 (infection / hemodynamics / organ_function)
```

**总参数量**：
- d_input=34 时：13,300
- d_input=4 时：476

### 当前叙事

> OPFA-QKAN-Mamba 是一个将医学本体知识编码进量子电路频率结构的 Mamba 混合模型。
> 它用 13,300 个参数（Transformer 的 1/5.4）达到了 0.8466 的 AUROC，同时提供了
> 经典模型无法提供的谱证书、频段可解释性和审慎推理能力。

### 存在的问题

1. **性能差距**：与 Transformer/GRU 差 ~4%（0.847 vs 0.883）
2. **消融反直觉**：去掉组件后性能略升，说明约束叠加过度限制了小模型
3. **Mamba 无加分**：Conv1d fallback 与 Mamba 性能相当，48 步序列太短
4. **叙事矛盾**：不能说"每个组件都提升性能"，因为消融不支持

### 可行的叙事角度

- **参数效率**：1/5 参数达到 95.8% 性能 ✓
- **QKAN 门控必要性**：无 QKAN 的 Mamba 只有 0.68 ✓
- **OPFA vs Original DARUAN**：+0.5% 且提供证书 ✓
- **安全保证**：唯一能提供谱证书的模型 ✓
- **可解释性**：频段贡献可精确归因 ✓
